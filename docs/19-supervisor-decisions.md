# Supervisor Decisions and Project Questions

These questions came from the project planning phase and should be updated as decisions are made. Keeping them in one document makes the final report easier to reconcile with the original plan.

## Moodle integration

- Is MoodleMock sufficient for the project scope?
- Is real Moodle integration expected, or is browser/API proof-of-concept work sufficient?

## Peppi integration

- Is PeppiMock sufficient for the project scope?
- Is real Peppi integration expected?

## Mailer/LianaMailer

- Is access to LianaMailer or a test environment available?
- Is MailerMock sufficient for demonstrating the communication workflow?

## CSC

- What CSC resources are available for deployment and testing?
- Are there networking restrictions affecting mock-service ports?
- Should the services run separately or behind a shared entry point?

## Telegram

- Is Telegram the primary student interaction channel?
- Should Telegram remain a demonstration channel or be integrated into the final prototype?

## WebUI

- Is OpenClaw WebUI customization mandatory?
- If the existing OpenClaw interface is sufficient, can custom UI work remain optional?
